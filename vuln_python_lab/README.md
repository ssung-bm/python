# ⚠️ VULNERABLE PYTHON LAB

**WARNING:** This project contains intentional security vulnerabilities for educational purposes only.

## Included Vulnerabilities:
- SQL Injection
- XSS (Reflected)
- Path Traversal
- Insecure Deserialization (Pickle)
- Hardcoded Secrets
- Weak Cryptography (MD5, AES-ECB)
- Vulnerable Dependencies

## Usage:
1. `pip install -r requirements.txt`
2. `flask run`
3. Audit the code in `app/` directory.

**DO NOT DEPLOY TO PRODUCTION.**
